# Developer Program başvuru hazırlığı

Resmî kayıt sayfası: https://github.com/developer/register

GitHub'ın yayımladığı iki koşul: GitHub API kullanan geliştirme/üretim aşamasında bir entegrasyon ve kullanıcıların destek için ulaşabileceği e-posta adresi.

## Başvuruda kullanılabilecek proje bilgileri

- Proje adı: GitHub Başarım Kontrolü
- Proje adresi: https://github.com/eCoxvague/Github-Basarimlar
- Kaynak: badge-check.mjs
- Durum: geliştirme aşamasında
- Açıklama: Bağımlılıksız Node.js CLI aracı. GitHub REST API'sinden herkese açık kullanıcı ve repo verilerini okur; görünür profil başarımlarını ve özgün repoların yıldız durumunu raporlar. Token istemez ve hesapta değişiklik yapmaz.
- Kullanılan API'ler: GET /users/{username}, GET /users/{username}/repos.
- Destek e-postası: Başvuranın kullanmayı seçtiği gerçek destek e-postası; burada otomatik doldurulmadı.

## Kayıt adımları

1. GitHub hesabınızla kayıt sayfasını açın.
2. Form farklı alanlar gösterirse yukarıdaki proje bilgilerini ilgili alanlara uyarlayın.
3. Kullanmayı seçtiğiniz gerçek destek e-postasını yazın.
4. Program sözleşmesini okuyup kabul kararını kendiniz verin.
5. Üyeliği ve profil göstergesini GitHub üzerinden doğrulayın.

Bu belge başvuru taslağıdır. Henüz kayıt yapıldığı, koşulların GitHub tarafından kabul edildiği veya rozet verildiği anlamına gelmez.

Kaynak: https://docs.github.com/en/integrations/concepts/github-developer-program
